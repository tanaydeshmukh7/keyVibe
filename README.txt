KEYVIBE UI REPAIR

This version fixes the clipped middle controls by using a scrollable responsive layout, transparent labels, consistent spacing, and compact sound controls. It keeps custom sound upload and the key-click duration slider. It also removes the invalid QCheckBox.setWordWrap() call.

INSTALL:
1. Close KeyVibe.
2. Back up your existing C:\Users\tanay\KeyVibe\main.py.
3. Copy this main.py into C:\Users\tanay\KeyVibe, replacing the old file.
4. In CMD, run:
   .venv313\Scripts\activate
   python main.py

No reinstall needed if your current environment works.
